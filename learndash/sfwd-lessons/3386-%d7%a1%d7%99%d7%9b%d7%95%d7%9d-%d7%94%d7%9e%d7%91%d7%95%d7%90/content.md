# סיכום המבוא

------------------------------------------------------------------------

בשלבים הקודמים סקרנו את הרעיון הכללי של מערכת ימה ואת מערכת האוסמוזה שעליה היא נשענת.  
המטרה הייתה להציג את העקרונות, היתרונות והדרישות הבסיסיות לפני שנצלול לשלבים המעשיים.

------------------------------------------------------------------------
